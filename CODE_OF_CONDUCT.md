# Code de conduite

L'Observatoire citoyen accueille les contributions et les désaccords argumentés. Les échanges doivent rester respectueux, précis et centrés sur les faits, les sources, la méthode ou le code.

Sont notamment attendus :

- critiquer une décision sans attaquer une personne ;
- distinguer une erreur factuelle d'un désaccord politique ;
- déclarer les conflits d'intérêts pertinents ;
- accepter la correction publique d'une erreur ;
- protéger les données personnelles et les personnes citées.

Le harcèlement, les menaces, les propos discriminatoires, la divulgation de données privées, la propagande coordonnée et la manipulation volontaire des sources ne sont pas acceptés.

Les mainteneurs peuvent masquer ou refuser un contenu, limiter une interaction ou exclure un participant lorsque ces règles ne sont pas respectées. Toute décision de modération importante doit être motivée et conservée autant que la protection des personnes le permet.
