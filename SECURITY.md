# Signaler une vulnérabilité

Cette politique concerne le code et les données destinés à la publication de Trace publique. Les documents de travail, secrets, comptes et éléments non publiés restent hors du dépôt public.

Ne publiez pas de vulnérabilité exploitable, de secret, de donnée personnelle ou de preuve sensible dans une issue publique.

Le canal privé de signalement sera indiqué ici avant l'ouverture publique du dépôt. Tant qu'il n'est pas disponible, contactez directement le mainteneur par un canal privé et fournissez uniquement les éléments nécessaires à la reproduction.

Un signalement utile contient :

- le composant et la version concernés ;
- l'impact estimé ;
- les étapes minimales de reproduction ;
- les conditions nécessaires à l'exploitation ;
- une proposition de correction, si elle existe.

Ne joignez pas de copie complète de données privées ou de fichiers de configuration à un signalement. Si aucun canal privé n'est encore indiqué, demandez au mainteneur un moyen de transmission confidentiel avant d'envoyer les détails.
